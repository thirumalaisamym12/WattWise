# WattWise — Energy Consumption Anomaly Detector

WattWise is a machine learning project that identifies unusual patterns in household electricity consumption using unsupervised anomaly detection.

## Project Goals
- Analyze household electricity consumption.
- Detect unusual consumption patterns using Isolation Forest.
- Build an interactive dashboard using Streamlit.
- Help users investigate potential energy inefficiencies.

## Technology Stack
- Python
- pandas and NumPy
- scikit-learn
- Plotly
- Streamlit
- joblib

## Project Status
Day 1: Development environment and GitHub setup.

## Dataset
UCI Individual Household Electric Power Consumption:
https://archive.ics.uci.edu/dataset/235/individual+household+electric+power+consumption

## Disclaimer
An anomaly is an unusual pattern; it does not necessarily indicate wasted electricity or faulty equipment.
